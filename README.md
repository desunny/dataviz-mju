# 융합데이터 시각화 · 학생 포트폴리오

명지대학교 융합데이터 시각화 수업 학생 작품 모음입니다.
GitHub Pages로 호스팅되어 발표 및 포트폴리오 용도로 사용됩니다.

## 구조

```
.
├── index.html          # 첫 화면 (반별 탭 + 학생 카드) — 자동 생성됨
├── generate_index.py   # index.html 생성기
└── 2026/               # 연도
    ├── 12/             # 12시 수업 (학번_이름.html)
    └── 15/             # 15시 수업 (학번_이름.html)
```

## 목록 갱신 방법

학생 작품(`연도/반/학번_이름.html`)을 추가·수정한 뒤 아래를 실행하면
`index.html`이 다시 만들어집니다.

```bash
python3 generate_index.py
git add -A && git commit -m "작품 추가/갱신" && git push
```

푸시 후 1~2분이면 사이트에 반영됩니다.

## 새 학기(연도) 추가

`2027/12/`, `2027/15/` 처럼 4자리 연도 폴더와 반 폴더를 만들고
같은 규칙(`학번_이름.html`)으로 파일을 넣은 뒤 위 갱신 절차를 실행하면
인덱스에 새 탭이 자동으로 추가됩니다.
